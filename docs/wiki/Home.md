# Start here

Graph Community helps turn a bounded GitHub issue into ordinary engineering work with native Codex. You choose the repositories, supply your own authenticated tools and retain authority over their actions. The coordinator reads an eligible issue, delegates implementation to an isolated worker, and records validation and PR disposition in GitHub.

Start with the [accounts-free local check](https://github.com/Vezryn-LLC/graph-community/blob/main/QUICKSTART.md#local-check-without-accounts-or-services). It requires no GitHub sign-in, model call or service installation. Before trying real work, read the same Quickstart's prerequisites and native-host qualification steps.

## What to trust

The [Quickstart](https://github.com/Vezryn-LLC/graph-community/blob/main/QUICKSTART.md), [architecture](https://github.com/Vezryn-LLC/graph-community/blob/main/ARCHITECTURE.md), [platform limits](https://github.com/Vezryn-LLC/graph-community/blob/main/PLATFORMS.md), [security policy](https://github.com/Vezryn-LLC/graph-community/blob/main/SECURITY.md) and [engineering library](https://github.com/Vezryn-LLC/graph-community/blob/main/docs/LIBRARY.md) are the maintained reference documents. This Wiki teaches tasks and points back to them.

[The latest public release](https://github.com/Vezryn-LLC/graph-community/releases/latest) is the place to obtain published artifacts. Tutorial links to `main` follow current documentation; check the matching release tag when using an older package. At this Wiki's first publication, the latest release is **v0.1.1**. Later documentation changes do not silently update installed software.

Graph Community is the public, headless coordinator. It does not include a desktop application, hosted control plane, company telemetry, accounts, model entitlements or private-product parity. A local check, capability report or PR alone does not prove universal platform support, autonomy or successful delivery. Read the specific evidence and limits in the reference documents.

The repository maintainers own this Wiki's upkeep. Contributors can suggest corrections through an issue or focused documentation PR; [Community and upkeep](https://github.com/Vezryn-LLC/graph-community/wiki/Community-and-Upkeep) explains the path. No recurring AI scan is required.
