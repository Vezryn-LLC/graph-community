# Execution Intent Preservation

## Objective
Keep the requested outcome ahead of speculative engineering.

## Practice
1. Identify whether the task is implementation, launch, prototype, review, investigation or operation.
2. Perform the requested action first; don't build unrelated infrastructure.
3. Fix only blockers that truly prevent the outcome.
4. Return to the original issue after repair.

Guidance only. Do not introduce new Graph services, approval gates or required reviewer loops.
