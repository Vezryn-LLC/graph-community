# Repair and Resume

- Preserve actual work and inspect the failure before repeating anything.
- Reproduce, fix and validate ordinary bugs; resume the original objective.
- Distinguish safely retryable failures from uncertain external GitHub writes or model outcomes.
- Check actual GitHub/process state before duplicating an uncertain side effect.
- Avoid broad reruns, speculative defensive layers and endless restart campaigns.
- Return the repaired artifact and remaining real blockers, not just a passing diagnostics report.
