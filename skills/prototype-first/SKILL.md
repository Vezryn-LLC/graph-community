# Prototype First

- Create the smallest demonstrable feature or interaction.
- Use existing tools and isolated source branches.
- Optimize for real user feedback; avoid speculative services, broad testing, telemetry and future-proofing.
- Provide a usable preview or direct reproduction path.
- Decide promote, revise or discard before hardening.
