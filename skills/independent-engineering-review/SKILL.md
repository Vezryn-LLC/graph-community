# Independent Engineering Review

## Objective
Review consequential risks only when warranted.

## Practice
1. Review actual changed source and acceptance evidence.
2. Target realistic failure hypotheses with material impact.
3. Distinguish blockers from optional YAGNI ideas.
4. Avoid rerunning review on unchanged source.
5. Separate security audit campaigns from routine feature delivery.

Guidance only. Do not introduce new Graph services, approval gates or required reviewer loops.
