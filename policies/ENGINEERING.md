# Engineering

Choose the smallest understandable implementation that satisfies the original
task. Reuse native tools and existing capabilities. Verify actual behavior;
inspect existing coverage, run focused affected checks, and add tests only for
distinct behavior, demonstrated regressions or material risk. Widen checks for
observed impact or required CI. Report actual versus simulated evidence honestly.

Routine changes need no second model review. Seek targeted independent review
for material security, authorization, credentials, billing, irreversible actions
or difficult-to-validate correctness. Do not substitute reports for working code.
Preserve user changes, unique commits and active source. Remove obsolete code
only when its remaining consumers are accounted for.
