# Issue Triage

## Task
An issue needs priority, duplicate, blocker or applicability assessment.

## Workflow
1. Read full GitHub issue, labels and related PRs.
2. Apply repository conventions and policies/ISSUE_SELECTION.md.
3. Identify real blockers and active claims.
4. Update labels/comments as appropriate; do not invent urgency or mandatory gates.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
