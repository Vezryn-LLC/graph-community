# Prepare Draft Pr

## Task
An implemented change needs publishing as a PR.

## Workflow
1. Verify branch, diff and matching existing PRs.
2. Push with native Git/GitHub capabilities.
3. Open or update a concise PR with actual test results.
4. Read back remote state; do not duplicate an uncertain create operation.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
