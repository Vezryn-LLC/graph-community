# Benchmark And Optimize

## Task
An issue requests measurable performance or cost improvement.

## Workflow
1. Establish a representative baseline.
2. Identify the actual bottleneck and implement the smallest change.
3. Run comparable after measurements and correctness checks.
4. Report result and tradeoffs; avoid speculative tuning.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
