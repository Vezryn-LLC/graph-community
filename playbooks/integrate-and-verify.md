# Integrate And Verify

## Task
Previously implemented components must work together.

## Workflow
1. Identify the actual integration boundary and existing work.
2. Connect only missing interfaces and avoid duplicate stacks.
3. Run a real representative end-to-end scenario.
4. Fix observed integration defects and provide the working artifact.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
