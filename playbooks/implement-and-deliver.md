# Implement and Deliver

**Use for:** actionable features and scoped improvements.

1. Read the original issue, relevant source and repository instructions; state the observable done condition.
2. Choose the smallest working implementation, using native tools and existing components.
3. Make changes on an issue-owned branch/worktree and verify actual behavior with appropriate focused checks.
4. Fix ordinary in-scope defects without starting a new campaign.
5. Use normal GitHub tools to publish the PR, report evidence and keep labels/issues accurate. Merge and close when repository workflow and permissions permit; don't make independent review a default stage.

**Useful skills:** `outcome-driven-engineering`, `change-aware-verification`. Stop when the feature demonstrably works and normal completion is recorded.
