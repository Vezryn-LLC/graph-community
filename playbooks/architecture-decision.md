# Architecture Decision

## Task
A concrete engineering tradeoff needs a decision.

## Workflow
1. State the actual requirement and constraints.
2. Inspect the existing approach before proposing another architecture.
3. Compare only practical alternatives; favor minimal reversible change.
4. Record the chosen design concisely, then return to delivery.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
