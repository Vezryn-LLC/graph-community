# Investigate And Recommend

## Task
Research or technical investigation is requested without implementation.

## Workflow
1. Define the decision or question.
2. Inspect actual source, records and relevant references.
3. Distinguish confirmed findings from hypotheses.
4. Provide a useful recommendation without silently building new infrastructure.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
