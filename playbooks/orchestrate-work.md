# Orchestrate Work

## Task
Independent issues can be delegated to Codex workers.

## Workflow
1. Select actionable issues using coordinator routing policies.
2. Assign independent branches/worktrees, playbooks and skills.
3. Continue dispatching while workers operate within native/hardware capacity.
4. React to completion and material blockers, not noisy polling or mandatory review loops.

## Completion
Return the actual deliverable and evidence, or a specific blocker. Follow `policies/ENGINEERING.md`; independent review is conditional. Use native Codex/GitHub tools and existing repository capabilities.
