# Rapid Prototype

**Use for:** new product ideas, UX concepts and speculative experiments.

1. Build the smallest runnable or interactive vertical slice with existing tools.
2. Demonstrate the actual experience; note limitations honestly.
3. Do only smoke-level verification initially. Avoid services, telemetry, broad CI and production hardening before the idea proves useful.
4. Publish an accessible preview or branch and state whether to **promote, revise or discard**.

**Useful skills:** `prototype-first`, `outcome-driven-engineering`. Never silently turn a prototype into a platform.
